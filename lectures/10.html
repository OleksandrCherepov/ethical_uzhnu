Утримання доступу (Persistence) та обхід антивірусів

2 год Нова

Огляд лекції

Ця лекція розглядає дві критичні теми пентесту: утримання доступу (Persistence) та обхід антивірусного захисту (Evasion). Студенти вивчать методи закріплення у Windows (Registry Run Keys, Scheduled Tasks, Services, WMI Event Subscriptions) та Linux (cron, SSH keys, systemd, SUID), класифіковані за MITRE ATT&CK TA0003.

Друга частина лекції присвячена інструменту msfvenom для генерації payload'ів у різних форматах (exe, elf, apk, war, ps1) та налаштуванню Multi/Handler. Завершуємо детальним аналізом роботи антивірусів (signature, heuristic, behavioral, AMSI, EDR) та сучасних технік evasion: encoders, packers/crypters, code obfuscation, Living Off the Land (LOLBins), fileless execution та AMSI bypass.

Теми лекції

  1. Вступ до Persistence — Концепція, MITRE ATT&CK TA0003, класифікація методів, етичні аспекти
  2. Windows Persistence — Registry Run Keys, Scheduled Tasks, Services, WMI, Startup, DLL Hijacking
  3. Linux Persistence — Cron, .bashrc, SSH Authorized Keys, systemd, SUID, rootkits
  4. msfvenom: створення payload'ів — Синтаксис, staged/stageless, формати, encoders, шаблони
  5. msfvenom: практика з Multi/Handler — Windows/Linux/Android/Web payloads, handler, доставка
  6. Як працюють антивіруси — Signature, heuristic, behavioral, sandbox, AMSI, EDR
  7. Обхід антивірусів (Evasion) — Encoders, packers, crypters, Veil, Shellter, obfuscation
  8. Сучасні техніки Evasion та захист — LOTL/LOLBins, fileless, AMSI bypass, sandbox evasion, detection
