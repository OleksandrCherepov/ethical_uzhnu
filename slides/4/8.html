Тема 4.8 — Сканування мережі та Enumeration

Кафедра ТЕІБ, Ужгородський національний університет

Техніки обходу IDS/фаєрволів

Сучасні IDS (Snort) алертують при 15+ просканованих портів/сек від одного джерела. Існують техніки обходу.

Фрагментація

nmap -f target # 8-байтні фрагменти nmap --mtu 24 target # Кастомний MTU

Розбиває TCP-заголовок на фрагменти. Деякі фаєрволи не вміють збирати.

Декої (Decoys)

nmap -D RND:10 target # 10 випадкових IP nmap -D 10.0.0.1,ME,10.0.0.2 target

Ціль бачить SYN від багатьох IP — не може визначити реальний.

Тайминг

nmap -T0 target # 5 хв між пробами nmap --scan-delay 5s target # 5-сек затримка nmap --max-rate 1 target # 1 пакет/сек

Маскування джерела

nmap --source-port 53 target # Маскування під DNS nmap --data-length 25 target # Рандомний padding nmap --spoof-mac 0 target # Випадковий MAC

Альтернативні інструменти

Характеристика Nmap Masscan RustScan
Швидкість Тисячі портів/сек 10M пакетів/сек 65535 портів за ~3с
Детекція сервісів Так (-sV) Тільки банери Передає в Nmap
ОС фінгерпринт Так (-O) Ні Через Nmap
NSE скрипти 600+ Ні Через Nmap
Найкраще для Детальний аналіз Масштабне виявлення Швидкий скан + Nmap
Оптимальний workflow: Masscan/RustScan для швидкого виявлення відкритих портів → Nmap для детального аналізу знайденого.

hping3 — крафтинг пакетів

hping3 -S target -p 80 -c 1 # Одиночний SYN hping3 -S target --scan 1-1024 # Скан діапазону hping3 -S -A target -p 80 # SYN+ACK тест

Підсумок лекції 4

Сканування мережі та Enumeration — це перехід від пасивної розвідки до активного збору інформації. Правильна методологія: від широкого до вузького, від швидкого до глибокого.

Ключові теми лекції:

TCP/IP: рукостискання, прапорці, порти — фундамент сканування
Типи сканів: SYN (стелс), Connect (без root), UDP (повільний)
Nmap: host discovery → port scan → version detect → OS fingerprint → NSE
Enumeration: SMB, SNMP, DNS, LDAP, NFS, SMTP, веб
Обхід IDS: фрагментація, декої, тайминг, маскування
Методологія: від широкого до вузького, завжди документувати
Далі: Лекція 5 — Фреймворк Metasploit та експлуатація.
