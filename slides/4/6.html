Категорії NSE скриптів

NSE — потужний скриптовий движок на Lua. Понад 600 скриптів для автоматизації аудиту, перелічення та пошуку вразливостей.
Категорія Опис Безпека

Ключові NSE скрипти

Пошук вразливостей

nmap --script vuln target
nmap -p445 --script smb-vuln-ms17-010 target
nmap -sV --script vulners target

Перелічення SMB

nmap -p445 --script smb-enum-shares,smb-enum-users target

Веб та SSL

nmap -p80 --script http-enum target
nmap -p443 --script ssl-enum-ciphers target

DNS та SMTP

nmap -p53 --script dns-zone-transfer --script-args dns-zone-transfer.domain=example.com target

nmap -p25 --script smtp-enum-users target

-sC = --script=default — запускає всі «безпечні» скрипти

Підсумок

NSE перетворює Nmap із сканера портів на повноцінний фреймворк для аудиту безпеки.
  • -sC запускає default скрипти (безпечні перевірки)
  • --script vuln — пошук відомих вразливостей (CVE)
  • --script vulners — звірка версій із базою CVE
  • smb-vuln-ms17-010 — перевірка EternalBlue
  • http-enum — пошук прихованих директорій та файлів
  • Завжди перевіряйте категорію скрипта перед запуском!
