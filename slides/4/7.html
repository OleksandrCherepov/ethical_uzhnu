Enumeration: збір детальної інформації

Тема 4.7 — Сканування мережі та Enumeration

Кафедра ТЕІБ, Ужгородський національний університет

SMB та NetBIOS Enumeration

Enumeration — глибокий збір інформації з виявлених сервісів: користувачі, ресурси, конфігурації, вразливості.

SMB Enumeration (порти 139, 445)

  • enum4linux — обгортка для rpcclient + smbclient
  • Null Session — автентифікація без пароля
  • Що отримуємо: користувачі, групи, шари, політика паролів
# Повний аудит SMB
enum4linux -a 192.168.1.100

# Список шар без автентифікації
smbclient -L //target -N

NetBIOS (порти 137-139)

  • nbtscan — масове сканування NetBIOS імен
  • Суфікси:
    • <00> = Workstation
    • <03> = User
    • <20> = Server
    • <1B> = Domain Controller
# Сканування підмережі
nbtscan 192.168.1.0/24

# Nmap NSE скрипт
nmap -sU -p137 --script nbstat target

SNMP та DNS Enumeration

SNMP (порт 161 UDP)

  • Community strings: "public" (read), "private" (write)
  • snmpwalk — обхід MIB-дерева
  • Інформація: процеси, ПЗ, інтерфейси, відкриті порти
# Обхід SNMP-дерева
snmpwalk -v 2c -c public target

# Брутфорс community strings
onesixtyone -c wordlist.txt target
OID Інформація
1.3.6.1.2.1.1.1.0 Опис системи
1.3.6.1.2.1.25.4.2.1.2 Запущені процеси
1.3.6.1.2.1.25.6.3.1.2 Встановлене ПЗ

DNS (порт 53)

  • Zone Transfer (AXFR) — повна копія зони
  • dnsrecon — автоматизована DNS-розвідка
  • fierce — словникова атака на субдомени
# Спроба zone transfer
dig axfr example.com @ns1.example.com

# Автоматична DNS-розвідка
dnsrecon -d example.com -t axfr
Увага! Правильно налаштований DNS-сервер обмежує AXFR лише авторизованим серверам. Але багато хто забуває це зробити.

LDAP, NFS, SMTP Enumeration

LDAP (порти 389, 636)

  • Active Directory: користувачі, групи, SPN (Kerberoasting)
  • ldapsearch — анонімний запит
# Анонімний LDAP-запит
ldapsearch -x \
  -H ldap://target \
  -b "dc=example,dc=com"

NFS (порти 111, 2049)

  • showmount — список експортованих шар
  • no_root_squash — небезпечна конфігурація
# Експортовані NFS-шари
showmount -e 192.168.1.100

SMTP (порт 25)

  • VRFY — перевірити існування користувача
  • RCPT TO — валідація email (не можна вимкнути!)
# Enum користувачів SMTP
smtp-user-enum \
  -M VRFY \
  -U users.txt \
  -t target

Веб-сервери та підсумок

Веб-enumeration

  • Nikto: сканер веб-вразливостей (6700+ перевірок)
  • Gobuster: брутфорс директорій та файлів
  • whatweb: визначення веб-технологій
# Сканування веб-вразливостей
nikto -h http://target

# Брутфорс директорій
gobuster dir -u http://target \
  -w /usr/share/wordlists/dirb/common.txt
Ключова думка: Enumeration — ключ до знаходження точок входу. Кожен відкритий сервіс — потенційний вектор атаки.

Протоколи для enumeration:

  • SMB/NetBIOS — користувачі, шари, політики
  • SNMP — системна інформація, процеси, ПЗ
  • DNS — zone transfer, субдомени
  • LDAP — структура Active Directory
  • NFS — експортовані файлові системи
  • SMTP — валідація користувачів
  • HTTP/HTTPS — директорії, технології, вразливості
