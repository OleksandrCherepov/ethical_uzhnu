Виявлення хостів (Host Discovery)

Nmap (Network Mapper) — створений Гордоном «Fyodor» Ліоном у 1997 році. Де-факто стандарт для мережевого сканування.
Прапорець Метод Опис
-sn Ping Scan Тільки виявлення, без сканування портів
-Pn Skip Ping Пропустити виявлення, сканувати всі
-PS443 TCP SYN Ping SYN на вказаний порт
-PA80 TCP ACK Ping ACK на вказаний порт
-PU UDP Ping UDP на високий порт
-PE ICMP Echo Класичний ping (Type 8)
-PP ICMP Timestamp Timestamp запит (Type 13)
-PR ARP Ping Найнадійніший у локальній мережі
# Швидке виявлення хостів
nmap -sn 192.168.1.0/24

Специфікація портів та тайминг

Порти

-p 22,80,443 Конкретні порти
-p 1-1024 Діапазон
-p- Усі 65535 портів
--top-ports 100 Топ-100 найпоширеніших
-F Швидкий (100 портів)

Тайминг-шаблони

Шаблон Назва Затримка Коли використовувати
-T0 Paranoid 5 хв Обхід IDS
-T1 Sneaky 15 сек Обхід IDS
-T2 Polite 0.4 сек Зменшити навантаження
-T3 Normal Авто Стандарт (дефолт)
-T4 Aggressive Швидко Надійна мережа
-T5 Insane Мінімум Швидкість > точність
Використовуйте -T4 на швидких мережах. -T0/-T1 для обходу IDS, але скан всієї підмережі займе години.

Формати виводу та практичні команди

Формати виводу

Прапорець Формат
-oN file Normal (текстовий)
-oX file XML (для програм)
-oG file Grepable (для grep/awk)
-oA base Усі три формати

Ключові команди

# 1. Швидке виявлення мережі
nmap -sn 192.168.1.0/24

# 2. Повне сканування цілі
nmap -sS -sV -O -sC -p- -T4 target

# 3. Топ-1000 портів + версії
nmap -sS -sV -T4 target

# 4. Агресивний скан
nmap -A -T4 target

# 5. UDP сервіси
nmap -sU -p 53,161,500 target

Підсумок

Nmap — це швейцарський ніж для мережевого сканування. Комбінація -sS -sV -O -sC -T4 покриває більшість потреб.
  • Host discovery: -sn для мережі, -Pn якщо фаєрвол блокує ping
  • Port scanning: -sS (SYN) дефолтний, -p- для повного сканування
  • Тайминг: -T4 для швидких мереж, -T1 для стелсу
  • Вивід: завжди зберігайте результати (-oA)
  • Агресивний режим: -A = -sV + -O + -sC + traceroute
