Social-Engineer Toolkit (SET)

SET v8.0.3 (TrustedSec, Дейв Кеннеді, 2009). Python 3, 2M+ завантажень. У Kali: /usr/share/set/. Запуск: sudo setoolkit.

Website Attack Vectors

  • Credential Harvester (Site Cloner)
  • Tabnabbing
  • Web Jacking (iframe-overlay)
  • Multi-Attack Web
  • HTA Attack (PowerShell)

Інші модулі

  • Spear-Phishing (PDF/DOCX payload)
  • Infectious Media Generator (USB)
  • Mass Mailer (SMTP, Gmail)
  • QRCode Generator
  • Powershell Attack Vectors
Обмеження: не клонує SPA (React/Angular) · CSP блокує iframe · Google Safe Browsing блокує клонів за години.
