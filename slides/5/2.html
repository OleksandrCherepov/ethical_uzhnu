Структура каталогів

/usr/share/metasploit-framework/

  • modules/ — exploits, payloads, auxiliary, post, encoders, nops
  • data/ — wordlists, templates, exploits DB
  • lib/ — бібліотеки Rex, MSF Core, MSF Base
  • plugins/ — розширення функціональності
  • scripts/ — meterpreter, shell scripts
  • tools/ — standalone утиліти

База даних

PostgreSQL backend

  • msfdb init — ініціалізація БД
  • msfdb start — запуск
  • db_status — перевірка підключення
  • Workspaces: ізоляція проєктів
  • Збереження hosts, services, vulns, creds, loot
  • Швидкий пошук та фільтрація

Запуск msfconsole
# Запуск консолі
msfconsole

# Запуск з підключенням до БД
msfconsole -q

# Виконати команду та вийти
msfconsole -x "use exploit/windows/smb/ms17_010_eternalblue; show options"

# Запустити resource script
msfconsole -r script.rc

Рекомендований інтерфейс

msfconsole — найпотужніший та найгнучкіший інтерфейс:

  • Повний доступ до всіх модулів
  • Tab-completion для команд та шляхів
  • Історія команд (↑/↓)
  • Інтеграція з PostgreSQL
  • Підтримка скриптів (resource files)
  • Найшвидша робота

Ключові факти

Модульність

Архітектура Rex → Core → Base → Modules забезпечує гнучкість та розширюваність

База даних

PostgreSQL зберігає результати сканування, credentials, loot — основа для великих проєктів

Інтерфейси

msfconsole — стандарт індустрії для exploit development та пентестів

Чому Metasploit — стандарт індустрії

  • Найбільша база експлойтів (2300+ модулів)
  • Open-source з активною спільнотою
  • Інтеграція з Nmap, Nessus, Burp Suite
  • Автоматизація через скрипти та resource files
  • Підтримка від Rapid7 та щомісячні оновлення
  • Документація та навчальні ресурси
