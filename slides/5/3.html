Exploit категорії

  • windows/ — Windows-специфічні
  • linux/ — Linux системи
  • unix/ — Unix-like системи
  • multi/ — кросплатформені
  • android/ — Android пристрої
  • osx/ — macOS

Auxiliary категорії

  • scanner/ — сканери сервісів
  • admin/ — адміністративні дії
  • fuzzers/ — фазінг протоколів
  • dos/ — DoS атаки
  • gather/ — збір інформації
  • server/ — фейкові сервіси

Пошук модулів

# Пошук за типом, платформою та сервісом search type:exploit platform:windows smb # Пошук за CVE номером search cve:2017-0144 # Пошук за назвою search name:eternalblue # Пошук за автором search author:hdm # Детальна інформація про модуль info exploit/windows/smb/ms17_010_eternalblue # Показати опції модуля show options

Поради для ефективного пошуку

  • Використовуйте множинні фільтри для точності: type:, platform:, name:
  • CVE пошук — найшвидший спосіб знайти експлойт для конкретної вразливості
  • Команда info показує опис, цілі, опції, посилання, дату
  • Використовуйте grep для фільтрації результатів: search smb | grep 2017
  • Перегляд ranking: Excellent → Great → Good → Normal
