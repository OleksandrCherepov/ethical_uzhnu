Вступ до експлуатації вразливостей

Тема 5.1 — Фреймворк Metasploit та експлуатація

Кафедра ТЕІБ, Ужгородський національний університет

Що таке експлуатація вразливостей?

Визначення: Експлуатація (exploitation) — це процес використання вразливості в системі для досягнення несанкціонованої мети: виконання коду, підвищення привілеїв, крадіжки даних або порушення доступності.

Вразливість vs Експлойт

Вразливість (Vulnerability)

Слабке місце в системі: помилка в коді, неправильна конфігурація, застарілий компонент

Експлойт (Exploit)

Код або техніка, яка використовує вразливість для компрометації системи

Cyber Kill Chain

1. Reconnaissance
2. Weaponization
3. Delivery
4. Exploitation ←
5. Installation
6. Command & Control
7. Actions on Objectives

Коли відбувається експлуатація: Після виявлення та аналізу вразливостей (фаза 4), тестувальник намагається підтвердити їх реальний вплив через контрольовану експлуатацію. Мета — отримати доступ до системи для подальшого пост-експлуатаційного аналізу (фаза 6).
⚠️ Етичні та правові межі: Експлуатація дозволена лише з письмовим дозволом власника системи і в межах визначеного scope. Несанкціонована експлуатація є кримінальним злочином (Computer Fraud and Abuse Act, Будапештська конвенція про кіберзлочинність, КК України ст. 361-363¹).

Типи експлойтів

Тип Опис Приклад
Remote Експлуатація через мережу без попереднього доступу EternalBlue (MS17-010), CVE-2021-44228 (Log4Shell)
Local Потребує локального доступу до системи Dirty COW (CVE-2016-5195), kernel exploits
Client-side Експлуатує застосунок на машині жертви (браузер, PDF reader) Browser exploits, malicious PDF/Office documents
Web Використовує вразливості веб-застосунків SQL Injection, XSS, Remote Code Execution через upload
DoS Порушує доступність сервісу (без отримання доступу) Buffer overflow crash, amplification attacks
Privilege Escalation Підвищує привілеї з користувача до root/SYSTEM Sudo exploits, Windows token manipulation

Zero-day vs N-day

Zero-day (0day)

Вразливість, невідома виробнику. Патч відсутній. Експлойт має максимальну цінність і ефективність.

N-day

Публічна вразливість з доступним патчем. Експлуатується на системах, де патч ще не встановлено (unpatched systems).

Підсумок теми 5.1

Ключова ідея: Експлуатація — це перетворення теоретичної вразливості в реальний доступ до системи. Це критична фаза пентесту, що підтверджує ризики та дозволяє перейти до пост-експлуатаційного аналізу глибини компрометації.
✓ Експлуатація — фаза 5 методології PTES (Exploitation)
✓ Вразливість — це слабке місце; експлойт — код, що його використовує
✓ Exploitation у Cyber Kill Chain: перехідна точка від підготовки до контролю
✓ Типи експлойтів: Remote, Local, Client-side, Web, DoS, Privilege Escalation
✓ Zero-day експлойти (невідомі виробнику) vs N-day (публічні, непатчені)
✓ Експлуатація дозволена лише з письмовим дозволом і в межах scope
