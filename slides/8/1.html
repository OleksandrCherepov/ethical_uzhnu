Cross-Site Scripting (XSS)

XSS — впровадження шкідливого JavaScript у сторінки, що переглядаються іншими користувачами. Порушує Same-Origin Policy — фундаментальний механізм безпеки браузера.

Reflected XSS

Payload у запиті, відображається у відповіді. Потрібен клік на посилання.

/search?q=<script>alert(1)</script>

Stored XSS

Payload зберігається на сервері. Атакує всіх відвідувачів. Найнебезпечніший.

Коментар: <img src=x onerror=alert(1)>

DOM-based XSS

Вразливість у клієнтському JS. Сервер може не бачити payload.

el.innerHTML = location.hash.slice(1)
CWE-79: Improper Neutralization of Input During Web Page Generation. OWASP A03:2021 — Injection.

DOM XSS: Sources та Sinks

Sources (звідки дані)

  • location.hash
  • location.search
  • document.URL
  • document.referrer
  • window.name
  • postMessage дані
  • localStorage / sessionStorage

Sinks (куди потрапляють)

  • innerHTML / outerHTML
  • document.write()
  • eval()
  • setTimeout(string)
  • location.href (javascript:)
  • jQuery.html()
  • insertAdjacentHTML()

Наслідки XSS

  • Крадіжка cookies та сесій
  • Keylogging (паролі, картки)
  • Фішинг у контексті довіреного сайту
  • Defacement сторінки
  • Криптомайнінг у браузері
  • XSS Worm (самопоширення)

Відомі інциденти

  • Samy Worm (2005) — 1M профілів MySpace
  • TweetDeck (2014) — self-retweet worm
  • British Airways (2018) — 380K карток, £20M штрафу
  • Fortnite (2019) — крадіжка акаунтів
