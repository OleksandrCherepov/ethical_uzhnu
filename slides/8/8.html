Крок 1: Mapping

  • Пройтись по всіх сторінках
  • Заповнити форми маркерами: test123xss
  • Знайти де дані відображаються
  • Site map → аналіз reflection points

Крок 2: Repeater

# Ctrl+R → надіслати в Repeater GET /search?q=test123xss # Визначити контекст: # HTML body? Attribute? JS? # Спробувати payload: GET /search?q=<img src=x onerror=alert(1)>

Крок 3: Stored XSS

  • Знайти форми збереження (коментарі, профіль)
  • Ввести payload у кожне поле
  • Перевірити ВСІ місця відображення
  • Включно з admin panel, email, PDF

Крок 4: DOM Invader

  • Вбудований браузер Burp → DOM Invader ON
  • "Inject canary into sources"
  • Автотрекінг sources → sinks
  • Кнопка "Exploit" для payload

Burp Intruder: автоматизація фазингу

Налаштування Intruder для XSS

# 1. Ctrl+I → надіслати в Intruder # 2. Позначити payload position: GET /search?q=§test§ HTTP/1.1 # 3. Payload type: Simple list # 4. Завантажити XSS wordlist: - PortSwigger XSS cheat sheet - SecLists/Fuzzing/XSS/ - PayloadsAllTheThings/XSS/ # 5. Grep → Match: alert( | onerror= | <script

Burp Suite модулі

  • Proxy — перехоплення запитів
  • Repeater — ручне тестування
  • Intruder — автоматичний фазинг
  • Collaborator — out-of-band
  • DOM Invader — DOM XSS
