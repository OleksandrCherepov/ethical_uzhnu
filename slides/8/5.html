Небезпечна десеріалізація

Десеріалізація ненадійних даних може привести до Remote Code Execution, Privilege Escalation, DoS та Authentication Bypass.

PHP

// ВРАЗЛИВО $obj = unserialize( $_COOKIE['data'] ); // __wakeup() або // __destruct() → RCE // БЕЗПЕЧНО $obj = json_decode( $_COOKIE['data'] );

Python

# ВРАЗЛИВО import pickle obj = pickle.loads(data) # __reduce__() → RCE # БЕЗПЕЧНО import json obj = json.loads(data)

Java

// ВРАЗЛИВО ObjectInputStream ois = new ObjectInputStream(in); Object obj = ois.readObject(); // Gadget chains → RCE // ysoserial — генерація // payload'ів
Правило: НІКОЛИ не десеріалізувати ненадійні дані. Використовувати JSON, protobuf, msgpack замість бінарної серіалізації.
