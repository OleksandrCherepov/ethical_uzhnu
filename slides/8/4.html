Фактори автентифікації та типові вразливості

Knowledge

Щось, що ви знаєте

  • Пароль
  • PIN
  • Секретне питання

Possession

Щось, що ви маєте

  • TOTP (Google Auth)
  • FIDO2 ключ
  • Смарт-карта

Inherence

Щось, що ви є

  • Відбиток пальця
  • Face ID
  • Голос

Типові атаки

  • Credential Stuffing — бази витечених паролів
  • Brute Force — перебір (Hydra, Burp)
  • Password Spraying — 1 пароль, багато акаунтів
  • Session Fixation — встановлення session ID
  • Session Hijacking — перехоплення через XSS

NIST 800-63B (2024)

  • Мінімум 8 символів, рекомендовано 15+
  • Не вимагати спецсимволів
  • Перевіряти у базах витоків
  • Не вимагати періодичної зміни
  • Дозволяти paste (менеджери паролів)

JWT та OAuth: вразливості

JWT атаки

  • alg=none — підпис не перевіряється
  • RS256→HS256 — confusion з публічним ключем
  • Weak secret — brute force через hashcat
  • Відсутній exp — токен ніколи не закінчується
  • kid injection — маніпуляція Key ID
# JWT brute force hashcat -m 16500 jwt.txt rockyou.txt

OAuth 2.0 атаки

  • Open Redirect — маніпуляція redirect_uri
  • CSRF на callback — відсутній state
  • Token leakage — access_token у Referer
  • Implicit flow — токен у URL (deprecated)
  • PKCE bypass — без code_verifier
OAuth 2.1 вимагає PKCE для всіх клієнтів і забороняє Implicit flow.
