Що логувати

  • Логін / логаут / невдалі спроби
  • Відмови в доступі
  • Помилки валідації вводу
  • Зміни привілеїв
  • Аномальні бізнес-операції
  • Зміни конфігурації

Чого НЕ логувати

  • Паролі, токени, API keys
  • Номери карток, SSN
  • PII без маскування

Алертинг та Incident Response

Типові правила алертингу

  • >5 невдалих логінів за 5 хв → Можливий brute force
  • Логін з нової геолокації → Підозрілий доступ
  • SQL-помилки у логах → Можлива SQLi
  • Сплеск 4xx/5xx → Сканування або атака
  • Зміна конфігурації поза робочими годинами → Компрометація
