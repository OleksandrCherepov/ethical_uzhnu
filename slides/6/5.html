rockyou.txt та SecLists

rockyou.txt — найвідоміший словник, створений з витоку 14,3 млн паролів сервісу RockYou у 2009 році. Входить до Kali Linux за замовчуванням.

rockyou.txt

  • 14,344,392 унікальних паролів
  • Шлях: /usr/share/wordlists/rockyou.txt.gz
  • Топ-10: 123456, 12345, 123456789, password, iloveyou, princess, 1234567, rockyou, 12345678, abc123
  • Розмір: ~133 MB (розпакований)

SecLists (Daniel Miessler)

  • Найбільша колекція словників для пентесту
  • Категорії: Passwords/, Usernames/, Discovery/, Fuzzing/
  • Ключові файли: xato-net-10-million, common-credentials, darkweb2017, leaked-databases
  • Шлях: /usr/share/seclists/
sudo apt install seclists

CeWL та Crunch — кастомні словники

CeWL (Custom Word List generator)

  • Генерує словник з вмісту веб-сайту
  • Збирає слова з HTML-сторінок (spider)
  • Ідеально для цільових атак
# Базове сканування
cewl https://target.com -d 2 -m 5 -w wordlist.txt
# -d 2 = глибина 2 рівні
# -m 5 = мінімум 5 символів

# З email-адресами
cewl https://target.com -e --email_file emails.txt

# З мутаціями
cewl https://target.com --lowercase -w words.txt

Crunch — генератор за шаблоном

  • Генерує ВСІ можливі комбінації
  • Можна вказати charset, pattern, довжину
# 6-8 символів, тільки цифри
crunch 6 8 0123456789 -o pins.txt

# За шаблоном: Слово + 4 цифри
crunch 8 8 -t Pass@@@@ -o list.txt

# @ = нижній регістр
# , = верхній регістр
# % = цифри
# ^ = спецсимволи
Увага: crunch 8 8 (всі символи) = 6.6 квадрильйонів рядків = 62 PB файл!

CUPP та Mentalist — соціальна інженерія

CUPP (Common User Password Profiler) створює словник на основі особистої інформації цілі: ім'я, дата народження, домашня тварина, хобі.

CUPP

  • Інтерактивний режим: запитує ім'я, прізвище, дату народження, nickname, ім'я партнера, дитини, тварини
  • Генерує мутації: John1990!, john_2024, J0hn#90
# Інтерактивний режим
cupp -i

# Завантажити список Alecto (defaults)
cupp -a

# З файлу конфігурації
cupp -l # парсити профіль

Mentalist (GUI)

  • Графічний генератор словників
  • Ланцюжок: Base Words → Mutations → Output
  • Мутації: Case toggle, Append numbers, Leet speak (a→@, e→3, o→0), Prepend year
  • Приклад: john → John, JOHN, j0hn, John2024!, john@123
  • Kwprocessor: генерація keyboard walks (qwerty, 1qaz2wsx)

Правила мутації Hashcat/JtR

Правила мутації — найефективніший підхід: маленький словник + розумні правила = мільйони варіантів.

Популярні правила Hashcat

Правило Опис password →
: Без змін password
l Lowercase password
u Uppercase PASSWORD
c Capitalize Password
$1 Append 1 password1
^! Prepend ! !password
sa@ Replace a→@ p@ssword
se3 Replace e→3 (leet speak) password
d Duplicate passwordpassword
r Reverse drowssap
# Вбудовані правила Hashcat
hashcat -m 0 -a 0 hashes.txt wordlist.txt -r /usr/share/hashcat/rules/best64.rule

# Кастомне правило: capitalize + append рік
echo 'c $2 $0 $2 $5' > custom.rule
hashcat -m 0 -a 0 hashes.txt wordlist.txt -r custom.rule
best64.rule + rockyou.txt зламують ~70% типових паролів.
