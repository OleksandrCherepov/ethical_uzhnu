John the Ripper

John the Ripper (JtR) — класичний крекер паролів з 1996 року. Версія Jumbo підтримує 300+ форматів хешів та працює на CPU.

Режими роботи

  • Single Crack — логін, GECOS, мутації
  • Wordlist — словникова атака з правилами
  • Incremental — повний перебір за charset
  • External — кастомні правила на C
# Словникова атака john --wordlist=rockyou.txt hashes.txt # З правилами мутації john --wordlist=rockyou.txt --rules=best64 hashes.txt # Incremental (brute-force) john --incremental=Alnum hashes.txt # Показати зламані john --show hashes.txt

*2john утиліти — конвертація у формат JtR

zip2john archive.zip > hash.txt
pdf2john doc.pdf > hash.txt
ssh2john id_rsa > hash.txt
rar2john file.rar > hash.txt
keepass2john db.kdbx > hash.txt
office2john doc.docx > hash.txt
wpapcap2john capture.cap > hash.txt

Hashcat — GPU-прискорений крекінг

Hashcat — найшвидший крекер у світі. Використовує GPU (CUDA/OpenCL) для паралельного обчислення мільярдів хешів/сек.
Режим (-a) Назва Опис
0 Dictionary Словникова атака (+ правила -r)
1 Combinator word1 + word2
3 Brute-force/Mask ?u?l?l?l?d?d?d?d
6 Hybrid Dict+Mask словник + ?d?d?d
7 Hybrid Mask+Dict ?d?d?d + словник
# MD5 словникова атака hashcat -m 0 -a 0 hashes.txt rockyou.txt # NTLM з правилами hashcat -m 1000 -a 0 hashes.txt rockyou.txt -r best64.rule # Маска: 8 символів (верхній + нижні + цифри) hashcat -m 0 -a 3 hashes.txt ?u?l?l?l?l?d?d?d # Гібридна: словник + 4 цифри hashcat -m 0 -a 6 hashes.txt rockyou.txt ?d?d?d?d

Hashcat: маски та популярні хеші

Символи масок

  • ?l = a-z (нижній регістр)
  • ?u = A-Z (верхній регістр)
  • ?d = 0-9 (цифри)
  • ?s = спецсимволи (!@#$...)
  • ?a = все (?l?u?d?s)
  • ?1 = кастомний charset (-1 ?l?d)
-m Формат Приклад
0 MD5 5f4dcc3b...
100 SHA-1 5baa61e4...
1000 NTLM 31d6cfe0...
1800 sha512crypt ($6$) $6$rounds$...
3200 bcrypt $2b$12$...
22000 WPA-PBKDF2-PMKID+EAPOL WPA2 handshake
13400 KeePass $keepass$...
Час крекінгу 8-символьного пароля (a-z+0-9) на RTX 4090: MD5 — 5 секунд, bcrypt — 27 років. Вибір алгоритму вирішує все!

Rainbow Tables та практичний workflow

Rainbow Tables

  • Попередньо обчислені хеші для пошуку
  • Компроміс час ↔ пам'ять
  • Таблиця для MD5 (a-z, 1-8 символів) ≈ 460 GB
  • Сіль повністю нейтралізує rainbow tables
  • Інструмент: RainbowCrack (rtgen, rtsort, rcrack)

Практичний workflow крекінгу

  • Ідентифікувати хеш: hashid або hash-identifier
  • Словникова атака: rockyou.txt
  • Словник + правила: best64, d3ad0ne
  • Гібридна: словник + маска
  • Маска з шаблоном: ?u?l?l?l?d?d?d?s
  • Повний перебір: останній варіант
# Ідентифікація хеша hashid '5f4dcc3b5aa765d61d8327deb882cf99' hash-identifier # Benchmark GPU hashcat -b -m 0
