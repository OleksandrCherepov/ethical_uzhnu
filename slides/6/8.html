Багатофакторна автентифікація (MFA)

MFA блокує 99.9% автоматизованих атак на паролі (Microsoft, 2023). Це єдиний найефективніший захисний механізм.

Фактори автентифікації

  • Знання (Something you know): пароль, PIN
  • Володіння (Something you have): телефон, токен, смарт-карта
  • Біометрія (Something you are): відбиток, обличчя
  • Місцезнаходження: IP, геолокація

Типи MFA

  • TOTP (Google Authenticator, Authy): 6-значний код кожні 30 сек
  • Push-сповіщення (Microsoft Authenticator, Duo): підтвердження на телефоні
  • SMS OTP: код через SMS (вразливий до SIM-swap!)
  • FIDO2/WebAuthn: апаратні ключі (YubiKey)
  • Passkeys: безпарольна автентифікація

Атаки на MFA

  • MFA Fatigue (push bombing): багато запитів поки жертва не натисне "дозволити"
  • SIM Swapping: перехоплення SMS через оператора
  • Evilginx2: фішинг з перехопленням MFA-токенів (reverse proxy)
  • Real-time phishing: relay сесії

Fail2ban, Rate Limiting та Account Lockout

Fail2ban

  • Моніторить логи на невдалі спроби входу
  • Блокує IP через iptables/nftables
  • Підтримує: SSH, Apache, Nginx, Postfix, vsftpd
# /etc/fail2ban/jail.local [sshd] enabled = true port = ssh filter = sshd logpath = /var/log/auth.log maxretry = 3 bantime = 3600 findtime = 600 # Перевірка статусу fail2ban-client status sshd

Account Lockout (AD)

  • Блокування після N невдалих спроб
  • Типово: 5 спроб → 30 хв lockout
  • Проблема: DoS через навмисне блокування
  • Smart lockout (Azure AD): блокує підозрілі IP, не легітимних
# Windows: Group Policy # Account lockout threshold: 5 # Account lockout duration: 30 min # Reset counter after: 15 min # CAPTCHA після 3 невдалих спроб # Progressive delays: 1s, 5s, 30s, 5min

Passkeys, FIDO2 та безпарольне майбутнє

Passkeys (FIDO2/WebAuthn) — заміна паролів. Google, Apple, Microsoft впровадили підтримку у 2023-2024. Неможливо зафішити або підібрати.

Як працюють Passkeys

  • Публічний ключ → сервер
  • Приватний ключ → пристрій (TPM/Secure Enclave)
  • Автентифікація: біометрія або PIN на пристрої
  • Фішинг-резистентні: прив'язані до домену
  • Синхронізація між пристроями (iCloud, Google)
  • Стандарт: WebAuthn (W3C) + CTAP2 (FIDO Alliance)

Апаратні ключі (YubiKey)

  • USB/NFC токен
  • FIDO2/U2F протоколи
  • Підтримка: Google, Microsoft, GitHub, AWS, Facebook
  • Захист від фішингу: криптографічна прив'язка до origin
  • Ціна: $25-70
  • Рекомендація: 2 ключі (основний + резервний)

Статистика впровадження (2025)

Google: 400M+ акаунтів з passkeys

Microsoft: passkeys за замовчуванням

Apple: iCloud Keychain passkeys

GitHub: підтримка з 2023

Підсумок лекції 6

Атаки на паролі — найпоширеніший вектор початкового доступу. Розуміння методів атаки необхідне для побудови ефективного захисту.

Ключові теми лекції:

Хешування паролів: MD5/SHA (швидкі, небезпечні) vs bcrypt/Argon2 (повільні, безпечні)
Офлайн: John the Ripper (CPU), Hashcat (GPU) — мільярди хешів/сек
Онлайн: Hydra, Medusa, Ncrack — брутфорс мережевих сервісів
Словники: rockyou.txt, SecLists, CeWL, CUPP, правила мутації
Wi-Fi: handshake/PMKID → aircrack-ng/hashcat
Credential Stuffing / Password Spraying — масові атаки
Захист: MFA, fail2ban, passkeys, NIST 800-63B
Далі: Лекція 7 — Безпека веб-додатків: OWASP Top 10 (Частина 1). Перехід від мережевих атак до атак на веб-додатки!

Рекомендації NIST 800-63B

  • Довжина > складність (мінімум 8, рекомендовано 12+)
  • Без обов'язкової ротації
  • Перевірка проти списків витоків
  • Заборона поширених паролів
  • MFA для критичних систем
