Persistence: навіщо і як

Persistence — техніки збереження доступу до системи після перезавантаження, зміни паролів або інших подій. MITRE ATT&CK: TA0003.

Boot/Logon

  • Registry Run Keys
  • Startup Folder
  • Services
  • Scheduled Tasks

Event-based

  • WMI Subscription
  • COM Hijacking
  • Image File Execution
  • AppInit DLLs

Linux

  • Cron Jobs
  • .bashrc / .profile
  • SSH Authorized Keys
  • Systemd Services
Етика: Документувати кожний механізм persistence. Після пентесту — обов'язково видалити всі backdoor'и (cleanup).
