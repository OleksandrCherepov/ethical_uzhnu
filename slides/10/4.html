Формати та encoders

Executable

  • exe — Windows PE
  • elf — Linux ELF
  • apk — Android
  • msi — Windows Installer
  • war / jar — Java
  • dll — Windows DLL
  • hta — HTML Application

Shellcode / Script

  • raw — Raw shellcode
  • c, csharp — Byte array
  • python, ruby — Scripting
  • powershell, ps1 — PS
  • vba, vba-exe — Office macros
  • base64, hex — Encoding
Top Encoder: x86/shikata_ga_nai — polymorphic XOR. Змінює binary pattern кожну ітерацію, але stub декодера сам є сигнатурою для сучасних AV.
