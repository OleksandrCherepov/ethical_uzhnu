Чому веб-додатки — ціль №1

За даними Verizon DBIR 2024, 26% усіх витоків даних пов'язані з атаками на веб-додатки. Веб-поверхня — найбільший вектор атаки.

Причини вразливості

  • Доступні з інтернету 24/7 — постійна експозиція до атакуючих
  • Складна архітектура — frontend + backend + DB + API + CDN
  • Швидка розробка → недостатнє тестування — presure to ship fast
  • Сторонні бібліотеки та компоненти — залежності зі своїми вразливостями
  • Людський фактор — помилки розробників, copy-paste коду

Анатомія HTTP запиту та відповіді

HTTP Запит

GET /api/users/123 HTTP/1.1 Host: example.com Cookie: session=abc123 Authorization: Bearer eyJhbG... User-Agent: Mozilla/5.0 Accept: application/json

HTTP Відповідь

HTTP/1.1 200 OK Content-Type: application/json Set-Cookie: session=abc123; HttpOnly X-Frame-Options: DENY Content-Security-Policy: default-src 'self' {"id": 123, "name": "Admin"}
⚠️ Важливо: Кожен заголовок — потенційний вектор атаки. Cookie без HttpOnly → XSS крадіжка сесії. Відсутній CSP → ін'єкція скриптів.
