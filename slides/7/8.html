Burp Suite — головний інструмент пентестера

Burp Suite (PortSwigger) — стандарт індустрії для тестування веб-додатків. Community Edition безкоштовна, Professional — $449/рік.

Основні модулі

  • Proxy — перехоплення та модифікація трафіку
  • Scanner — автоматичне сканування (Pro)
  • Intruder — автоматизовані атаки (brute-force, fuzzing)
  • Repeater — ручне відправлення модифікованих запитів
  • Decoder — кодування/декодування (Base64, URL, HTML)
  • Comparer — порівняння відповідей
  • Sequencer — аналіз якості токенів

Корисні розширення (BApp Store)

  • Autorize — автоматична перевірка access control
  • Logger++ — розширений журнал запитів
  • JWT Editor — маніпуляція JWT токенами
  • Active Scan++ — додаткові перевірки сканера
  • Param Miner — знаходження прихованих параметрів
  • Turbo Intruder — швидший Intruder (Python)
  • Hackvertor — конвертація payload encodings

OWASP ZAP — безкоштовна альтернатива

OWASP ZAP (Zed Attack Proxy) — безкоштовний open-source сканер. Ідеальний для навчання та DevSecOps (CI/CD інтеграція).

Функції ZAP

  • Proxy — перехоплення HTTP/HTTPS
  • Spider — автоматичний обхід додатку
  • Active Scan — пошук вразливостей (SQLi, XSS, etc.)
  • Passive Scan — аналіз трафіку без змін
  • Fuzzer — автоматичний fuzzing параметрів
  • HUD — Heads Up Display у браузері
  • API для автоматизації (REST)
# ZAP у командному рядку zap-cli quick-scan http://target.com # Docker docker run -t owasp/zap2docker-stable \ zap-full-scan.py -t http://target.com # API автоматизація (Python) from zapv2 import ZAPv2 zap = ZAPv2(apikey='key') zap.spider.scan('http://target.com') zap.ascan.scan('http://target.com')

Nikto, Gobuster та Nuclei

Nikto — сканер веб-сервера

  • 6,700+ перевірок
  • Дефолтні файли, misconfiguration
  • Застарілі версії серверів
# Базовий скан nikto -h http://target.com # Конкретний порт nikto -h target.com -p 8080 # Вивід у HTML nikto -h target -o report.html

Gobuster / Feroxbuster

  • Брутфорс директорій та файлів
  • DNS субдомени, vhosts
# Директорії gobuster dir \ -u http://target.com \ -w /usr/share/seclists/\ Discovery/Web-Content/\ common.txt # Субдомени gobuster dns -d target.com \ -w subdomains.txt

Nuclei — template-based scanner

  • 8000+ шаблонів (CVE, miscfg, exposure)
  • Швидкий, масштабований
# Повний скан nuclei -u http://target.com # За тегом nuclei -u target \ -tags cve,sqli # Оновити шаблони nuclei -update-templates
