Кафедра ТЕІБ, Ужгородський національний університет

OWASP Foundation

OWASP (Open Worldwide Application Security Project) — неприбуткова організація, заснована у 2001 році. Місія: покращення безпеки програмного забезпечення через відкриті проекти.

Ключові проекти OWASP

  • Top 10 — класифікація критичних веб-вразливостей
  • ASVS — стандарт верифікації безпеки
  • Testing Guide — методологія тестування (v4.2)
  • Cheat Sheet Series — практичні рекомендації
  • ZAP — безкоштовний сканер вразливостей
  • SAMM — модель зрілості безпеки
  • Juice Shop — навчальний вразливий додаток

Історія Top 10

  • 2004 — перша версія
  • 2007 — друга ревізія
  • 2010 — акцент на ризиках
  • 2013 — оновлення методології
  • 2017 — data-driven підхід
  • 2021 — поточна версія (3 нові категорії)
  • 2025 — очікується оновлення

Еволюція: 2017 → 2021

Що змінилось

  • A01 Injection (2017) → A03 (2021) — знизився
  • A05 Broken Access Control (2017) → A01 (2021) — піднявся!
  • A03 Sensitive Data Exposure → A02 Cryptographic Failures (перейменовано)
  • A04 XXE → об'єднано з A05 Security Misconfiguration
  • A08 Insecure Deserialization → об'єднано з A08 Software Integrity

Нові категорії 2021

  • A04 Insecure Design (НОВА) — помилки архітектури та дизайну
  • A08 Software and Data Integrity Failures (НОВА) — CI/CD, десеріалізація, залежності
  • A10 SSRF (НОВА) — Server-Side Request Forgery
  • Об'єднання XSS з Injection (A03)
  • XXE → A05 Security Misconfiguration

Головний тренд: від технічних вразливостей (injection) до архітектурних проблем (insecure design, broken access control).
