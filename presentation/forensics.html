Огляд

Цифрова форензика у CTF-змаганнях

Форензика у CTF: що це?

85% CTF містять форензику
6 Основних категорій
200+ Інструментів
Jeopardy Найпоширеніший формат

Типи завдань

  • Аналіз файлів — формати, метадані, вбудовані об'єкти
  • Аналіз дисків — образи, видалені файли, файлові системи
  • Аналіз пам'яті — дампи RAM, процеси, ін'єкції
  • Мережева форензика — PCAP, потоки, протоколи
  • Стеганографія — приховані дані в медіафайлах
  • Аналіз логів — EVTX, syslog, таймлайни

Чому форензика важлива?

  • Прямий зв'язок із реальними розслідуваннями (DFIR)
  • Розвиває аналітичне мислення та увагу до деталей
  • Кросдисциплінарність: мережі + ОС + криптографія
  • Затребуваність на ринку: DFIR-аналітик

Форензика — єдина категорія CTF, де кожне завдання моделює реальний інцидент.

Арсенал форензика

Аналіз дисків

Autopsy / Sleuth Kit

Повнофункціональна платформа аналізу образів дисків

# Sleuth Kit — CLI
mmls disk.img            # таблиця розділів
fls -r -o 2048 disk.img  # список файлів
icat -o 2048 disk.img 65 # витягти файл за inode
blkcat disk.img 1024      # вміст блоку
  • Підтримка: NTFS, FAT, EXT, HFS+, APFS
  • Autopsy — GUI з таймлайном та пошуком

Карвінг файлів

Відновлення файлів без метаданих файлової системи

# Foremost — класичний карвер
foremost -t all -i disk.img -o output/

# Scalpel — швидший, конфігурується
scalpel -c scalpel.conf -o out/ disk.img

# Binwalk — вбудовані файли та firmware
binwalk -e firmware.bin
  • photorec — відновлення медіафайлів
  • bulk_extractor — паралельний аналіз

# Мережа та з'єднання

Поглиблений аналіз

# Дамп процесу та DLL

# Реєстр Windows

# Файли в пам'яті
vol -f mem.raw windows.filescan
  • windows.hashdump — хеші паролів
  • windows.handles — відкриті хендли

Мережева форензика

Wireshark Display Filters

# HTTP-трафік
http.request.method == "POST"
http contains "flag"

# DNS-запити
dns.qry.name contains "suspicious"

# TCP-потоки
tcp.stream eq 5

# TLS/SSL
tls.handshake.type == 1

tshark (CLI)

tshark -r capture.pcap -Y "http"
tshark -r capture.pcap -T fields -e http.host
tshark -r capture.pcap --export-objects http,out/

Перші команди

# Визначити тип файлу
file mystery_file
xxd mystery_file | head

# Метадані
exiftool mystery_file

# Пошук рядків
strings -n 8 mystery_file
strings -e l mystery_file  # UTF-16

# Вбудовані файли
binwalk mystery_file

Отримати прапорець

"Low-Hanging Fruit" — перевірте першими

  • file + strings + exiftool на кожен файл
  • binwalk -e — вбудовані файли
  • grep -r "flag\|CTF\|{" . — прямий пошук
  • Перевірити кінець файлу (дані після EOF)
  • Порівняти розмір файлу з очікуваним
  • Спробувати змінити розширення файлу
  • Base64, hex, ROT13 на підозрілі рядки

Типові помилки

  • Пропуск метаданих — EXIF часто містить підказки
  • Ігнорування strings — паролі, URL, ключі
  • Один інструмент — різні tools бачать різне
  • Пропуск alternate data — ADS в NTFS, resource forks
  • Неуважність до часових зон — UTC vs локальний

Правило: якщо щось виглядає не так — це підказка!
