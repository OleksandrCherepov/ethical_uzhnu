Розділи програми ЄДКІ

  • Нормативно-правове забезпечення
  • ІТ у сфері кібербезпеки
  • Безпека інформаційно-комунікаційних систем
  • Комплексні системи захисту інформації
  • Управління ІБ та кібербезпекою
  • Криптографічний захист
  • Технічний захист інформації

Мережева безпека

Аналіз трафіку, захист мереж, IDS/IPS

Аналіз мережевого трафіку

Wireshark

Захоплення та аналіз пакетів на рівні протоколів. Демонструє TCP-рукостискання, DNS-запити, HTTP-обмін

Nmap

Сканер мережі: відкриті порти, версії сервісів, визначення ОС. SYN-скан, UDP-скан, скрипти NSE

Netcat

Мережева утиліта для TCP/UDP: перевірка портів, передача файлів, створення простих серверів

Зв'язок з ЄДКІ

Розділ «ІТ у сфері кібербезпеки»: структура TCP/IP-пакетів, модель OSI, протоколи, поняття сокета та порту

Захист мереж: Firewall та VPN

Міжмережеві екрани

  • iptables / nftables — фільтрація пакетів у Linux: ланцюжки INPUT/OUTPUT/FORWARD
  • pfSense / OPNsense — програмні брандмауери з веб-інтерфейсом
  • Концепції: NAT, DMZ, stateful vs stateless

VPN-технології

  • OpenVPN / WireGuard — сучасні VPN-рішення
  • IPSec — AH vs ESP, транспортний vs тунельний режим
  • SSL/TLS — захист каналів зв'язку
  • Site-to-site та Remote Access VPN

Зв'язок з ЄДКІ

Розділ «Безпека ІКС»: пакетний фільтр vs проксі, компоненти IPSec, призначення DMZ, принципи NAT

IDS/IPS та SIEM

Виявлення вторгнень

Snort / Suricata — мережеві IDS/IPS (NIDS). Сигнатурний аналіз, виявлення аномалій

OSSEC / Wazuh — хостові IDS (HIDS). Аналіз логів, контроль цілісності файлів, виявлення rootkit'ів

Моніторинг (SIEM)

Splunk — комерційна платформа збору та аналізу логів

ELK Stack — Elasticsearch + Logstash + Kibana: агрегація та візуалізація

Зв'язок з ЄДКІ

NIDS vs HIDS; сигнатурний vs аномальний аналіз; IDS (виявлення) vs IPS (запобігання); кореляція подій; реагування на інциденти

Криптографія та доступ

Шифрування, автентифікація, захист ОС

Криптографічні інструменти

OpenSSL

SSL/TLS, генерація ключів, сертифікати, шифрування. Практична робота з RSA, AES, хеш-функціями

GnuPG (GPG)

Стандарт OpenPGP: шифрування файлів, електронний підпис, управління ключами

Hashcat / John the Ripper

Аналіз стійкості паролів. Демонструє хеш-функції, сіль, обчислювальну складність

CyberChef

Веб-інструмент: кодування (Base64, XOR), шифрування (AES), хешування — все в одному

Зв'язок з ЄДКІ

Симетричне (AES, DES, ГОСТ) vs асиметричне (RSA, El Gamal); ЕЦП; Diffie-Hellman; режими шифрування (ECB, CBC, CTR)

Управління доступом та автентифікація

Інструменти та протоколи

  • Active Directory — служба каталогів, реалізує DAC, MAC, RBAC
  • Kerberos — мережева автентифікація: TGT, KDC, сервісні квитки
  • RADIUS / TACACS+ — протоколи AAA
  • PAM — модульна автентифікація Linux

Моделі доступу

МодельПринцип
DACВласник визначає доступ
MACМітки конфіденційності, рівні допуску
RBACДоступ на основі ролей

MFA: знання + володіння + біометрія

Захист ОС та антивірусні технології

Безпека операційних систем

  • SELinux / AppArmor — мандатний контроль доступу (MAC) у Linux
  • Group Policy — політики безпеки Windows
  • ASLR, DEP/NX — захист пам'яті від експлойтів
  • VMware / Hyper-V / KVM — віртуалізація (Type 1 vs Type 2)

Антивірусні інструменти

  • ClamAV — сигнатурний антивірус (open source)
  • YARA — правила ідентифікації шкідливого ПЗ
  • VirusTotal — мультисканерна перевірка
  • Cuckoo / Any.Run — sandbox-аналіз поведінки

Зв'язок з ЄДКІ

Архітектура ОС (ядро, user space); файлові системи та ACL; методи виявлення шкідливого ПЗ (сигнатурний, евристичний, поведінковий)
